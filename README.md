# CSS Questions Repository

Welcome to the **CSS Questions** repository!  
This project is designed for anyone who wants to **practice CSS styling with real, hands-on exercises**.

---

## Repository Structure

Each question has **its own folder**, and inside it you will find:

### 1. `question.txt`

This file includes the **problem description** — what UI or layout you need to build.

### 2. `expected-output.png` (or .jpg)

A screenshot showing what your final output **should look like**.

### 3. `index.html`

This is the **starter HTML file**.  
➡️ The goal is to **practice CSS**, so you should _not_ change the HTML structure unless the question asks you to.

### 4. `style.css`

This is where you write your CSS code to match the expected output.

---

## How to Use This Repository

1. **Clone the repository:**

```bash
git clone https://github.com/Altamash-khn/CSS-Questions.git
```

2. Open any question folder
3. Read the problem in `question.txt`
4. Open the `index.html` and `style.css` files
5. Use the **expected-output image** to guide your design
6. Try to recreate the layout using **only CSS**
7. Compare your result with the expected screenshot

---

## Goal of This Repository

The main purpose is to help you improve in:

- CSS layouts
- Flexbox & Grid
- Styling and spacing
- Recreating UI from a design
- Building real-world components

---

## Contributions

Want to add your own CSS challenges?

1. Create a new folder
2. Add:
   - `question.txt`
   - `expected-output.png`
   - `index.html`
   - `style.css`
3. Submit a pull request
